# 다국어 수업자료 변환기 (PPTX · HWPX)

교사가 **한국어 `.pptx`(PowerPoint) 또는 `.hwpx`(한컴오피스 한글 표준 문서)** 수업자료를 업로드하고 대상 언어를 선택하면, 브라우저 안에서 편집 가능한 텍스트를 추출해 번역 초안을 만들고 교사의 비교·수정·검토를 거쳐 원본과 동일한 형식(`.pptx` / `.hwpx`)의 번역 파일을 다운로드하는 정적 웹 애플리케이션입니다.

- **배포 URL (GitHub Pages)**: `https://gmlduqzhd123-lab.github.io/Translation/`

---

## 1. 주요 기능 및 지원 범위

- **원문 언어**: 한국어 (`ko`)
- **대상 언어 (5개 언어 중 1개 선택)**:
  - 영어 (`en` - English)
  - 중국어 간체 (`zh-Hans` - 中文(简体))
  - 베트남어 (`vi` - Tiếng Việt)
  - 일본어 (`ja` - 日本語)
  - 러시아어 (`ru` - Русский)
- **지원 파일 형식**: `.pptx`, `.hwpx` (입력 형식과 동일한 형식으로 결과 파일 생성)
  - 구형 이진 포맷인 `.ppt`, `.hwp`는 직접 처리하지 않으며, 업로드 시 각각 `.pptx`, `.hwpx`로 다시 저장하는 방법을 안내합니다.
- **자동 번역 및 수동 입력 지원**:
  - 지원 브라우저(데스크톱 Chrome 최신 버전)에서는 내장 **Translator API (`window.Translator`)**를 사용해 외부 서버 전송 없이 자동 번역 초안을 생성합니다.
  - 자동 번역을 지원하지 않는 브라우저(모바일, Safari, Firefox 등)나 언어 조합에서도 텍스트 추출·직접 번역문 입력·파일 생성 및 다운로드 기능을 모두 사용할 수 있습니다.
- **개인정보 및 보안**:
  - 백엔드 서버, 데이터베이스, 외부 번역 API를 일체 사용하지 않습니다.
  - 업로드한 문서와 추출된 문장은 100% 사용자의 브라우저 메모리 안에서만 처리됩니다.

---

## 2. 제외 범위 및 주의사항

- **번역 제외 대상**: 이미지(그림) 속에 그려진 텍스트, 스캔 문서, PDF, 동영상·음성, 암호가 설정된 문서
- **다운로드 후 문서 배치 확인 필수**:
  - 번역문이 반영된 `.pptx`·`.hwpx` 파일은 원본의 도형·표·이미지와 기본 구조를 유지하지만, 한국어보다 번역문(영어·베트남어·러시아어 등)이 길어져 **글자 넘침, 줄바꿈 변경, 표 셀 높이 변화**가 생길 수 있습니다.
  - 다운로드한 결과 파일은 반드시 **PowerPoint** 또는 **한컴오피스 한글**에서 직접 열어 글자 크기와 상자 배치를 최종 확인한 뒤 수업에 활용하세요.
