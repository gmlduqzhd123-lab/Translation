# 다국어 수업자료 변환기 (PPTX · HWPX)

교사가 **한국어 `.pptx`(PowerPoint) 또는 `.hwpx`(한컴오피스 한글 표준 문서)** 수업자료를 업로드하고 대상 언어를 선택하면, 브라우저 안에서 편집 가능한 텍스트를 추출해 번역 초안을 만들고 교사의 비교·수정·검토를 거쳐 원본과 동일한 형식(`.pptx` / `.hwpx`)의 번역 파일을 다운로드하는 정적 웹 애플리케이션입니다.

- **배포 URL (GitHub Pages)**: `https://gmlduqzhd123-lab.github.io/Translation/`

---

## 1. 주요 기능 및 지원 범위

- **원문 언어**: 한국어 (`ko`)
- **대상 언어 (10개 언어 중 1개 선택)**:
  - **핵심 5개 국어**: 영어 (`en` - English), 중국어 간체 (`zh-Hans` - 中文(简体)), 베트남어 (`vi` - Tiếng Việt), 일본어 (`ja` - 日本語), 러시아어 (`ru` - Русский)
  - **다문화 학급 확장 5개 국어**: 우즈베크어 (`uz` - Oʻzbekcha), 몽골어 (`mn` - Монгол), 태국어 (`th` - ภาษาไทย), 캄보디아어/크메르어 (`km` - ភាសាខ្មែរ), 필리핀어/타갈로그어 (`tl` - Tagalog / Filipino)
- **지원 파일 형식**: `.pptx`, `.hwpx` (입력 형식과 동일한 형식으로 결과 파일 생성)
  - 구형 이진 포맷인 `.ppt`, `.hwp`는 직접 처리하지 않으며, 업로드 시 각각 `.pptx`, `.hwpx`로 다시 저장하는 방법을 안내합니다.
- **자동 번역(3단계 하이브리드) 및 수동 입력 지원**:
  - 1순위: 데스크톱 Chrome 최신 버전의 내장 **Translator API (`window.Translator`)**를 사용해 온디바이스 초안을 생성합니다.
  - 2순위: 브라우저 내장 API를 지원하지 않는 환경이나 확장 언어에서는 무료 신경망 번역 폴백(Google GTX → MyMemory)을 통해 자동 번역 초안을 제공합니다.
  - 3순위: 오프라인 환경 등에서도 텍스트 추출·직접 번역문 입력·외부 번역기 일괄 붙여넣기·파일 생성 및 다운로드 기능을 모두 사용할 수 있습니다.
- **6대 번역 품질 검증 도구 (외국어를 몰라도 검토 가능)**:
  - 🔄 **한국어 역번역(Back-Translation) 검증**: 외국어 번역문을 다시 한국어로 역번역하여 의미 왜곡이나 누락 여부를 한국어로 즉시 대조합니다.
  - 🚦 **신호등 정확도 자동 진단**: 숫자·날짜·퍼센트 누락, 원문 미번역, 문장 길이 급증(레이아웃 넘침 위험), 학교 행정/교과 용어집 불일치를 실시간으로 점검해 `🟢 안심` / `🟡 주의` / `🔴 확인 필요`로 안내합니다.
  - 📚 **학교·수업 표준 용어집 (68개 핵심 표현, 10개 국어)**: 가정통신문, 준비물, 모둠 활동, 수행평가 등 학교 현장 필수 용어의 표준 번역을 원클릭으로 삽입·일괄 적용합니다.
  - 🔊 **원어민 발음 듣기 (TTS)**: 브라우저 음성 합성(`speechSynthesis`)으로 번역문 발음을 바로 확인합니다.
- **2가지 문서 출력 방식 지원**:
  - **번역문 단독 교체**: 한국어 원문 자리에 외국어 번역문만 깔끔하게 넣습니다.
  - **한국어 원문 + 번역문 함께 표기(병기)**: 한국어 원문 줄 아래에 외국어 번역문을 나란히 넣어 교사·학생·학부모가 함께 볼 수 있는 이중언어 수업자료/가정통신문을 만듭니다.
- **개인정보 및 보안**:
  - 별도의 자체 백엔드 서버나 데이터베이스를 일체 사용하지 않으며, 문서 파싱·조립·임시 저장(IndexedDB)은 사용자의 브라우저 안에서만 처리됩니다.

## 2. 제외 범위 및 주의사항

- **번역 제외 대상**: 이미지(그림) 속에 그려진 텍스트, 스캔 문서, PDF, 동영상·음성, 암호가 설정된 문서
- **다운로드 후 문서 배치 확인 필수**:
  - 번역문이 반영된 `.pptx`·`.hwpx` 파일은 원본의 도형·표·이미지와 기본 구조를 유지하지만, 한국어보다 번역문(영어·베트남어·러시아어 등)이 길어져 **글자 넘침, 줄바꿈 변경, 표 셀 높이 변화**가 생길 수 있습니다.
  - 다운로드한 결과 파일은 반드시 **PowerPoint** 또는 **한컴오피스 한글**에서 직접 열어 글자 크기와 상자 배치를 최종 확인한 뒤 수업에 활용하세요.
