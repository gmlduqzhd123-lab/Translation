# 다국어 수업자료 변환기 (PPTX · HWPX) & 수업 활용 사례 공유

교사가 **한국어 `.pptx`(PowerPoint) 또는 `.hwpx`(한컴오피스 한글 표준 문서)** 수업자료를 업로드하고 대상 언어를 선택하면, 브라우저 안에서 편집 가능한 텍스트를 추출해 번역 초안을 만들고 교사의 비교·수정·검토를 거쳐 원본과 동일한 형식(`.pptx` / `.hwpx`)의 번역 파일을 다운로드하는 교육용 웹 애플리케이션입니다. 또한 교사가 실제 수업에서 도구를 활용한 사례를 작성·검토·공유할 수 있는 **수업 활용 사례 공유 및 관리자 승인 기능**을 제공합니다.

- **대상 저장소**: `https://github.com/gmlduqzhd123-lab/Translation`
- **배포 URL (GitHub Pages)**: `https://gmlduqzhd123-lab.github.io/Translation/`
- **공모 분야**: 2026년 초등 AI수업도구 제안전 ‘언어장벽 없는 수업’

## 1. 핵심 기능 및 작동 방식

### 1.1 다국어 수업자료 변환 (PPTX · HWPX)
- **원문 언어**: 한국어 (`ko`)
- **대상 언어 (25개 언어 중 1개 선택)**:
  - **핵심 5개 국어**: 영어 (`en`), 중국어 간체 (`zh-Hans`), 베트남어 (`vi`), 일본어 (`ja`), 러시아어 (`ru`)
  - **다문화 학급 확장 20개 국어**: 중국어 번체 (`zh-Hant`), 우즈베크어 (`uz`), 몽골어 (`mn`), 태국어 (`th`), 캄보디아어/크메르어 (`km`), 필리핀어/타갈로그어 (`tl`), 인도네시아어 (`id`), 미얀마어/버마어 (`my`), 네팔어 (`ne`), 스리랑카어/신할라어 (`si`), 힌디어 (`hi`), 벵골어 (`bn`), 파키스탄어/우르두어 (`ur`), 카자흐어 (`kk`), 키르기스어 (`ky`), 아랍어 (`ar`), 스페인어 (`es`), 프랑스어 (`fr`), 포르투갈어 (`pt`), 튀르키예어 (`tr`)
- **지원 파일 형식**: `.pptx`, `.hwpx` (입력 형식과 동일한 형식으로 결과 파일 생성)
  - 구형 이진 포맷(`.ppt`, `.hwp`)은 업로드 시 각각 `.pptx`, `.hwpx`로 다시 저장하는 변환 절차를 안내합니다.
  - 개인정보가 없는 예시 파일(`sample-science-lesson.pptx`, `sample-science-activity.hwpx`)을 기본 제공하여 즉시 전체 흐름을 체험할 수 있습니다.
- **실제 번역 처리 경로 (외부 번역 서버 자동 전송 없음)**:
  - **자동 번역**: 데스크톱 Chrome/Edge 최신 버전의 브라우저 내장 온디바이스 **Translator API (`window.Translator`)**만을 사용하여 기기 안에서 번역 초안을 생성합니다. 데이터 보관 및 모델 학습 제외 조건이 입증되지 않은 외부 무료 번역 API로 수업자료를 자동 전송하지 않습니다.
  - **수동 작업 경로 (미지원 환경·언어 완벽 대응)**: `window.Translator`를 지원하지 않는 브라우저나 언어팩 미지원 환경에서도 **텍스트 추출 → 학교 표준 용어집 일괄 적용 → 원문 전체 복사 / 외부 번역문 줄 단위 일괄 붙여넣기 → 문장별 직접 수정 → 번역 파일 생성 및 다운로드**의 전체 과정을 100% 완료할 수 있습니다.

### 1.2 교사 번역 검수 및 통합 경고 요약 (신호등 진단)
- **통합 검수 경고 요약 패널 (Step 4)**:
  - 다음 5가지 위험 요소를 자동 점검하여 한곳에 모아 보여줍니다:
    1. **숫자·날짜·퍼센트 누락** (`missing-number`)
    2. **한글 미번역 잔존** (`leftover-hangul`)
    3. **물음표(?) 누락** (`missing-question`)
    4. **번역문 길이 급증 (180% 초과, 레이아웃 넘침 위험)** (`length-overflow`)
    5. **학교 표준 용어집 불일치** (`glossary-mismatch`)
    6. **한국어 역번역 의미 차이 주의** (`back-translation-diff`)
  - 경고 항목을 클릭하면 해당 문장 카드로 즉시 이동하여 포커스하며, 교사가 번역문을 수정하거나 **`[✓ 확인 완료 표시]`**로 상태를 전환할 수 있습니다.
  - 다운로드 전(Step 5) **미확인 경고 수**를 표시하고, 자동 경고가 번역 정확성을 100% 보증하지 않으므로 교사의 최종 검토와 원본 프로그램(PowerPoint/한글) 배치 확인이 필수임을 안내합니다.
- **학교·수업 표준 용어집 (25개 국어)**: 가정통신문, 준비물, 모둠 활동, 수행평가 등 학교 현장 필수 용어의 표준 번역을 원클릭으로 삽입·일괄 적용합니다.
- **원어민 발음 듣기 (TTS)**: 브라우저 내장 음성 합성(`window.speechSynthesis`)으로 번역문 발음을 확인합니다.

### 1.3 수업 활용 사례 공유 및 서버 권한 검증 관리자 탭
- **독립 작동 보장**: 수업 활용 사례 공유 서버에 장애가 발생하거나 오프라인 상태여도 기존의 PPTX·HWPX 번역 및 다운로드 기능은 영향 없이 100% 정상 작동합니다.
- **교사 사례 작성 및 상태 조회**:
  - 필수 항목(제목, 활용 날짜, 학교급·학년, 교과, 대상 언어, 자료 형식, 수업 목표, 도구 사용 과정, 교사의 번역 검수·수정 내용, 관찰한 결과와 한계)과 선택 항목(학급·교원 수 등 집계 수치, 개선 사항, 공개 표시 이름)을 입력합니다.
  - 학생 개인정보(이름·연락처·사진·개별 학습 이력·개별 평가 결과) 입력란을 두지 않으며, 제출 전 3대 필수 확인란(실제 활용 사실, 학생 개인정보 제거, 공개 권한 확인)에 동의해야 합니다.
  - 제출 직후 작성자에게 **“관리자 승인중”** 상태가 표시되며, 승인 전에는 공개 목록이나 공유 링크에 노출되지 않습니다.
  - 작성자는 제출 시 설정한 작성자 확인 비밀번호로 본인의 글 상태(`관리자 승인중` / `승인됨` / `반려됨` 및 반려 사유)를 조회하고, 반려된 글을 수정해 재제출하거나 삭제할 수 있습니다.
- **공개 사례 탐색 및 예시 구분**:
  - 관리자 승인을 거친 사례만 공개 목록에 표시되며 언어·학년·교과·자료 형식으로 필터링하고 고유 링크(`?case=<id>`)로 공유할 수 있습니다.
  - 체험용으로 제공되는 샘플 데이터에는 **`[예시 사례 · 실제 실적 아님]`** 배지를 명확히 표시하여 실제 수업 실적과 혼동되지 않도록 구분합니다.
- **서버 검증 기반 관리자 탭**:
  - 승인·반려(사유 필수)·비공개 전환·삭제 및 신고 처리는 화면 숨김 방식이 아니라 **Supabase PostgreSQL `SECURITY DEFINER` RPC 함수 내부에서 관리자 비밀번호 해시(`pgcrypto` bcrypt)를 검증**한 뒤에만 수행됩니다.

### 2.2 브라우저 임시 저장 통제 방법
- 화면 상단 **브라우저 임시 저장 통제 바**에서 언제든지 **`이 브라우저에 작업 자동 임시 저장 (IndexedDB)`** 체크박스를 켜거나 끌 수 있습니다.
- 자동 저장을 끄는 즉시 브라우저 `IndexedDB`에 저장되어 있던 기존 문서와 번역 데이터는 즉시 삭제됩니다.
- **`[🗑️ 이 브라우저의 작업 내용 삭제]`** 버튼을 누르면 현재 브라우저에 저장된 원본 파일과 번역 작업 내용이 완전히 삭제되며, 새로고침해도 복원되지 않습니다.
- 교무실·컴퓨터실 등 **공용 PC**에서 작업한 경우, 다운로드 완료 화면(Step 5)의 안내에 따라 반드시 작업 내용을 삭제한 뒤 브라우저를 종료하시기 바랍니다.

## 3. 사례 공유 저장·운영 구조 (아키텍처)

GitHub Pages 정적 호스팅의 한계를 보완하고 다수 교사의 사례 공유 및 관리자 승인 권한을 안전하게 검증하기 위해 **Supabase (PostgreSQL + Row Level Security + SECURITY DEFINER RPC)** 구조를 사용합니다.

1. **저장 항목과 저장 위치**:
   - 저장 위치: Supabase PostgreSQL (`public.translation_lesson_cases`, `public.translation_case_reports`, `public.translation_admin_config`)
   - 저장 항목: 사례 메타데이터(제목, 활용일, 학년, 교과, 언어, 자료 형식), 수업 기록 본문(목표, 과정, 검수 내용, 결과·한계), 상태(`pending` / `approved` / `rejected` / `hidden`), 반려 사유, 작성자 비밀번호의 `pgcrypto` bcrypt 해시(`author_passcode_hash`), 3대 서약 동의 여부.
2. **작성자 인증 및 본인 글 확인 방법**:
   - 별도 회원가입을 요구하지 않고, 글 제출 시 작성자가 설정한 4자 이상의 비밀번호를 서버에서 `crypt(passcode, gen_salt('bf'))`로 해시하여 저장합니다.
   - 작성자 조회(`get_my_translation_cases`), 수정 후 재제출(`resubmit_translation_case`), 본인 글 삭제(`remove_my_translation_case`) 시 서버 RPC가 해시 일치 여부를 검증합니다.
3. **관리자 인증과 권한 확인 방법**:
   - 클라이언트 HTML·JavaScript·Git 저장소 어디에도 관리자 비밀번호 평문을 포함하지 않습니다.
   - 관리자 비밀번호는 DB의 비공개 테이블(`public.translation_admin_config`, RLS로 외부 직접 조회 차단)에 bcrypt 해시로만 저장되며, 모든 관리자 작업(`admin_list_translation_cases`, `admin_review_translation_case`, `admin_change_translation_password`, `admin_list_case_reports`, `admin_resolve_case_report`) 호출 시마다 서버 함수가 해시를 직접 대조합니다. 권한 없는 사용자가 API를 직접 호출하더라도 `UNAUTHENTICATED` 오류가 반환되어 승인·반려·삭제가 불가능합니다.
   - 실제 학교·교육청 운영 시에는 관리자 탭의 **`[🔐 비밀번호 변경]`** 기능을 통해 즉시 강한 비밀번호로 변경할 수 있습니다.
4. **승인 전 비공개 처리 방식**:
   - 제출된 모든 글은 기본 상태가 `pending`(`관리자 승인중`)으로 저장됩니다.
   - 공개 목록 조회(`SELECT` RLS 정책 및 `get_approved_translation_cases` RPC)는 `status = 'approved'`인 행만 반환하므로, 미승인·반려·비공개 글은 일반 사용자나 공유 링크에 절대 노출되지 않습니다.
5. **글 수정·비공개·삭제 절차와 보관 기간**:
   - **작성자 직접 처리**: ‘내 제출 글 확인’에서 작성자 비밀번호로 인증 후 반려된 글을 수정·재제출하거나 즉시 영구 삭제할 수 있습니다.
   - **신고 및 요청 경로**: 각 공개 사례 상세 화면의 **`[🚨 신고 · 수정/삭제 요청]`** 버튼을 통해 개인정보 포함 우려나 수정·삭제 요청을 접수할 수 있으며, 관리자가 관리자 탭에서 확인 후 즉시 비공개(`hidden`) 또는 영구 삭제(`delete`) 처리합니다.
   - **보관 기간**: 승인된 사례는 서비스 운영 기간 동안 보관하되 작성자 또는 관리자의 삭제 시 즉시 DB에서 영구 파기됩니다. 반려되거나 비공개 전환된 글은 작성자 소명·수정을 위해 최대 90일간 보관 후 관리자 점검 시 삭제합니다.
6. **접근 통제 및 장애 대응**:
   - 모든 테이블에 Row Level Security(RLS)가 활성화되어 있으며, 클라이언트의 임의 `UPDATE` / `DELETE`가 원천 차단되어 있습니다.
   - 사례 공유 서버 연결 실패 시 `src/case-sharing-service.js`가 자동으로 로컬 예시 사례 폴백 모드로 전환하여 화면 오류를 방지하며, 문서 번역 기능에는 어떠한 영향도 주지 않습니다.

## 4. 사용 안내 및 제한 사항

### 4.1 6단계 표준 사용 흐름
1. **파일 준비 (Step 1)**: 개인정보가 없는 `.pptx` 또는 `.hwpx` 수업자료를 준비해 업로드하거나, 화면의 **예시 파일(`초등 과학 PPTX` / `초등 과학 HWPX`)** 버튼을 클릭합니다. (`.ppt`, `.hwp`는 원본 프로그램에서 `다른 이름으로 저장`으로 변환 후 사용)
2. **언어 선택 (Step 2)**: 10개 대상 언어 중 수업에 필요한 언어 1개를 선택합니다.
3. **번역 실행 (Step 3)**: 지원 브라우저에서는 온디바이스 자동 번역을 실행하고, 미지원 환경에서는 수동 입력 모드로 진입합니다.
4. **교사 검수 (Step 4)**: **통합 검수 경고 요약 패널**에서 숫자 누락·용어집 불일치·길이 급증 경고를 클릭해 문장을 수정하거나 **`[✓ 확인 완료 표시]`**로 점검하고, 필요 시 외부 번역기 결과를 줄 단위로 일괄 붙여넣습니다.
5. **다운로드 (Step 5)**: 미확인 경고 수와 출력 방식(번역문 단독 교체 / 한·외국어 병기)을 확인한 뒤 결과 파일을 다운로드합니다. 공용 PC라면 **`[🗑️ 지금 작업 내용 삭제하기]`**를 클릭합니다.
6. **원본 프로그램에서 배치 확인**: 다운로드한 `.pptx`·`.hwpx` 파일을 PowerPoint 또는 한컴오피스 한글에서 열어 글자 크기, 줄바꿈, 표 셀 높이를 최종 확인합니다.

### 4.2 지원 기기·브라우저 및 알려진 제한 사항
- **문서 텍스트 추출·수동 편집·용어집·파일 다운로드**: 데스크톱 및 태블릿의 Chrome, Edge, Whale, Safari, Firefox 최신 버전에서 모두 작동합니다.
- **온디바이스 자동 번역 (`window.Translator`)**: 데스크톱 Chrome / Edge 138 이상에서 우선 지원되며, 기기 사양이나 언어팩 지원 여부에 따라 일부 확장 언어는 수동 번역/일괄 붙여넣기 모드로 안내됩니다.
- **번역 제외 대상**: 이미지(그림) 속에 그려진 글자, 스캔 문서, PDF, 동영상·음성, 암호가 설정된 문서(DRM 포함)는 텍스트를 추출할 수 없습니다.
