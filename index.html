📌 구형 .hwp 또는 .ppt 파일이신가요? (10초 만에 .hwpx·.pptx로 바꾸는 법) ▼

구형 이진 문서(.hwp, .ppt)는 직접 읽을 수 없습니다. 아래 순서대로 [다른 이름으로 저장]만 해주시면 바로 사용 가능합니다.

한글 문서 (.hwp → .hwpx)

  1. 한컴오피스 한글에서 원본 .hwp 파일을 엽니다.
  2. 상단 메뉴 [파일] → [다른 이름으로 저장하기]를 누릅니다.
  3. 아래쪽 [파일 형식]을 한글 표준 문서 (*.hwpx)로 바꾼 뒤 저장합니다.

파워포인트 (.ppt → .pptx)

  1. PowerPoint에서 원본 .ppt 파일을 엽니다.
  2. 상단 메뉴 [파일] → [다른 이름으로 저장]을 누릅니다.
  3. 파일 형식을 PowerPoint 프레젠테이션 (*.pptx)으로 선택해 저장합니다.

📋 다운로드 후 꼭 확인해 주세요! (PowerPoint · 한글에서 열어보기)

이 도구는 원본 문서의 사진·도형·표 구조를 그대로 유지하지만, 외국어 문장 길이가 한국어와 달라 배치가 조금씩 바뀔 수 있습니다. 수업에 쓰시기 전에 반드시 PowerPoint 또는 한컴오피스 한글에서 파일을 열어 아래 4가지를 확인해 주세요.

  • 1. 글자 넘침 조절하기: 영어·베트남어·러시아어 문장이 한국어보다 길어져 글상자 밖으로 넘치면, 상자를 넓히거나 글자 크기를 1~2pt 줄여 주세요.
  • 2. 표 줄바꿈 확인하기: 표 칸(셀) 안의 글자가 길어져 표가 다음 쪽으로 넘어가거나 줄바꿈이 어색한 곳이 있는지 살펴봐 주세요.
  • 3. 그림 속 한국어 확인하기: 그림(이미지) 파일 안에 그려져 있던 글자는 번역되지 않으므로, 필요한 경우 그림 옆에 작은 설명 상자를 추가해 주세요.
  • 4. 글꼴(폰트) 깨짐 확인하기: 특수 한글 글꼴이 적용된 곳에서 외국어 성조나 글자가 네모(□)로 보이면 ‘맑은 고딕’이나 ‘Arial’ 같은 기본 글꼴로 바꿔 주세요.

💡 수업 활용 사례 공유

📌 수업 활용 사례 열람 및 작성 안내

• 작성된 사례는 제출 직후 “관리자 승인중” 상태로 저장되며, 관리자가 개인정보 미포함 여부 등을 검토해 승인한 사례만 공개 목록에 게시됩니다.
• 게시된 사례라는 사실만으로 수업 실적이 공식 검증된 것을 뜻하지 않으며, [예시 사례] 배지가 붙은 글은 기능 이해를 돕기 위한 샘플이므로 실제 수업 실적과 구분됩니다.

📘 다국어 수업자료 변환기 사용 설명서

별도의 프로그램 설치나 회원가입 없이 5단계 순서대로 클릭만 하면 다국어 수업자료가 완성됩니다.

1단계

수업자료 파일 올리기 (.pptx 또는 .hwpx)

컴퓨터에 있는 한국어 파워포인트(.pptx)나 한글 표준 문서(.hwpx)를 선택하거나 마우스로 끌어다 놓습니다. 파일이 없다면 화면 아래 [예시 PPTX / HWPX 바로 불러오기] 버튼으로 먼저 연습해 볼 수 있습니다.

2단계

추출된 한국어 원문 확인하기

슬라이드 순서(PPTX) 또는 문단 순서(HWPX)대로 뽑아낸 문장 목록을 눈으로 확인하고 [다음: 번역할 언어 선택하기]를 누릅니다.

3단계

대상 언어(10개 국어) 선택 및 자동 번역 실행

영어, 중국어 간체, 베트남어, 일본어, 러시아어, 우즈베크어, 몽골어, 태국어, 캄보디아어(크메르어), 필리핀어(타갈로그어) 중 하나를 고르고 [🤖 선택한 언어로 자동 번역 초안 만들기]를 누릅니다. (직접 입력이나 외부 번역기 일괄 붙여넣기를 원하시면 [직접 번역문 입력하기]로 진행할 수 있습니다.)

4단계

역번역·신호등 진단·용어집으로 검토하고 ‘확인 완료’ 체크

왼쪽 한국어 원문과 오른쪽 번역문을 비교하며 다듬습니다. 외국어를 몰라도 🔄 한국어 역번역 검증, 🚦 정확도 신호등(숫자·용어 점검), 📚 학교 표준 용어집으로 쉽게 확인할 수 있습니다. (단축키: 입력창에서 Ctrl + Enter를 누르면 바로 확인 완료 처리 후 다음 문장으로 넘어갑니다!)

5단계

출력 방식(단독 교체 / 원문+번역문 병기) 선택 후 다운로드

빠진 문장이 없는지 최종 확인하고 번역문 단독 교체 또는 한국어 원문 + 번역문 함께 표기(병기) 방식을 선택한 뒤 [📥 번역된 수업자료 파일 다운로드]를 누르면 원본과 똑같은 형식(.pptx 또는 .hwpx)으로 저장됩니다.

예전 방식의 .hwp와 .ppt 파일은 문서 구조가 잠겨 있어 브라우저에서 직접 열 수 없습니다. 아래 방법으로 10초 만에 변환해 주세요.

📝 한컴오피스 한글: .hwp를 .hwpx로 저장하기

  1. 한컴오피스 한글(2014 이상)에서 가지고 계신 .hwp 파일을 엽니다.
  2. 왼쪽 위 메뉴에서 [파일] → [다른 이름으로 저장하기](단축키 Alt + V)를 누릅니다.
  3. 저장 창 아래쪽의 [파일 형식(T)] 목록을 클릭합니다.
  4. 한글 표준 문서 (*.hwpx)를 선택한 뒤 [저장]을 누릅니다.
  5. 새로 만들어진 .hwpx 파일을 이 사이트에 업로드합니다.

📊 Microsoft PowerPoint: .ppt를 .pptx로 저장하기

  1. PowerPoint에서 가지고 계신 .ppt 파일을 엽니다.
  2. 왼쪽 위 메뉴에서 [파일] → [다른 이름으로 저장](단축키 F12)을 누릅니다.
  3. 파일 이름 아래의 [파일 형식] 목록을 클릭합니다.
  4. 맨 위에 있는 PowerPoint 프레젠테이션 (*.pptx)을 선택하고 [저장]을 누릅니다.
  5. 새로 만들어진 .pptx 파일을 이 사이트에 업로드합니다.
🔒 문서에 열기 암호나 배포용 문서 설정이 되어 있나요?

암호가 걸린 문서는 내용을 읽을 수 없습니다. 한글이나 파워포인트에서 암호를 해제하고 일반 .hwpx·.pptx로 저장한 뒤 올려 주세요.

이 웹앱은 학생·수업 자료를 외부 번역 서버로 보내지 않기 위해 컴퓨터의 Chrome 브라우저 안에 내장된 인공지능 번역기(Translator API)를 사용합니다.

체크 1

데스크톱 Chrome(크롬) 브라우저로 접속했나요?

스마트폰·태블릿(모바일)이나 사파리(Safari), 구형 브라우저에서는 내장 자동 번역 기능이 제공되지 않습니다. PC용 Google Chrome 최신 버전에서 접속해 주세요.

체크 2

처음 번역할 때 ‘모델 다운로드 중’이라고 나오나요?

정상입니다! 해당 언어를 처음 번역할 때 Chrome이 내 컴퓨터로 언어 사전(모델)을 내려받습니다. 잠시 기다려 100%가 되면 바로 번역이 시작되며, 다음번부터는 대기 시간 없이 즉시 번역됩니다.

체크 3

자동 번역이 안 되는 컴퓨터에서도 사용할 수 있나요?

네! 3단계에서 [✍️ 자동 번역 없이 직접 번역문 입력하기] 버튼을 누르면 추출된 문장 옆에 직접 번역문을 입력하거나 복사해 붙여넣어 완벽하게 번역된 .pptx·.hwpx 파일을 만들 수 있습니다.

한국어보다 영어·베트남어·러시아어는 단어와 문장 길이가 약 1.3~1.8배 길어집니다. 다운로드한 파일을 연 뒤 아래 방법으로 다듬어 주시면 훨씬 깔끔한 수업자료가 됩니다.

📊 PowerPoint(.pptx) 다듬기 꿀팁

  • 글자가 상자 밖으로 삐져나올 때: 해당 글상자 테두리를 클릭하고 글꼴 크기를 1~3pt 줄이거나, 상자 가로 폭을 살짝 넓혀 주세요.
  • 줄바꿈이 어색할 때: 단어 중간에서 줄이 바뀌었다면 자연스러운 위치에서 Shift + Enter로 줄을 맞춰 주세요.

📝 한컴오피스 한글(.hwpx) 다듬기 꿀팁

  • 표 높이가 늘어나 다음 쪽으로 넘어갈 때: 표 전체를 블록 지정(F5 세 번)한 뒤 글자 크기를 1pt 줄이거나 줄 간격을 130~140%로 조절해 보세요.
  • 특수 글꼴에서 외국어가 깨질 때: 전체 선택(Ctrl + A) 후 다국어가 모두 잘 나오는 맑은 고딕 또는 함초롬돋움으로 글꼴을 바꿔 주세요.
