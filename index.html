📌 구형 .ppt · .hwp 파일 변환 안내

이진 형식인 .ppt와 .hwp 파일은 직접 처리하지 않습니다. 아래 방법으로 다시 저장한 뒤 업로드해 주세요.

  • .ppt → .pptx 저장 방법:
    PowerPoint에서 파일 열기 → [파일] > [다른 이름으로 저장] → 파일 형식을 PowerPoint 프레젠테이션(*.pptx)으로 선택해 저장
  • .hwp → .hwpx 저장 방법:
    한컴오피스 한글에서 파일 열기 → [파일] > [다른 이름으로 저장하기] → 파일 형식을 한글 표준 문서(*.hwpx)로 선택해 저장

🔍 지원 범위 및 제외 대상 안내

  • 원문 및 대상 언어: 한국어 → 영어, 중국어 간체, 베트남어, 일본어, 러시아어 (1개 선택)
  • 추출 대상: 슬라이드 텍스트 상자, 제목·부제목, 표 셀, 한글 문단 및 글상자 내 편집 가능한 텍스트
  • 번역 제외 대상: 이미지(그림) 속에 포함된 글자, 스캔 문서, PDF, 동영상·음성, 암호가 설정된 문서
  • 서식 안내: 기본 도형·이미지·표 구조는 유지되나, 번역문 길이 변화로 인한 줄바꿈·배치는 다운로드 후 문서 프로그램에서 최종 확인해야 합니다.

📋 다운로드 후 필수 확인 사항 (문서 프로그램에서 열기)

번역된 파일은 원본의 이미지·도형·표와 기본 문서 구조를 유지하지만, 모든 문서에서 원본 서식이 완벽히 유지되지는 않습니다. 수업에 배포하기 전에 반드시 실제 문서 프로그램(PowerPoint 또는 한컴오피스 한글)에서 파일을 열어 아래 항목을 확인해 주세요.

  • 1. 글자 넘침 및 상자 크기 확인: 한국어보다 영어·러시아어·베트남어 등의 문장 길이가 길어져 텍스트 상자나 도형 밖으로 글자가 넘치면 글꼴 크기를 줄이거나 상자 크기를 넓혀 주세요.
  • 2. 표 셀 줄바꿈 및 행 높이 확인: 표 셀 안의 번역문이 길어져 줄바꿈 위치가 어색하거나 표가 페이지/슬라이드를 벗어나는지 확인해 주세요.
  • 3. 이미지 속 글자 확인: 그림(이미지) 파일 내부에 포함된 한국어 텍스트는 자동 변환되지 않으므로 필요한 경우 별도 설명 상자를 추가해 주세요.
  • 4. 대상 언어 글꼴(폰트) 표시 확인: 베트남어 성조 기호, 중국어 간체 한자, 러시아어 키릴 문자가 깨지지 않는 글꼴(예: 맑은 고딕, Arial, Noto Sans 등)로 표시되는지 확인해 주세요.
